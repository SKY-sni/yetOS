# yetOS

**yetOS** — операционная система с открытым исходным кодом, разрабатываемая как форк **ByteOS**[cite: 1, 2]. Проект развивает наработки оригинальной системы, делая упор на глубокую оптимизацию ядра, улучшение графической подсистемы и стабильность[cite: 1, 2].

---

## 🌟 Ключевые возможности

* **Форк ByteOS:** развитие и модернизация кодовой базы с фокусом на производительность, чистую архитектуру и исправление ошибок[cite: 1, 2].
* **Универсальная загрузка:** поддержка современного режима **UEFI** и классического **Legacy BIOS** на базе загрузчика **Limine**[cite: 1, 2].
* **Графический интерфейс:** встроенная оконная оболочка, рабочий стол и базовые приложения прямо из коробки[cite: 1, 2].
* **Оптимизация и скорость:** минимальная нагрузка на CPU и RAM, плавная работа GUI и переработанные системные вызовы[cite: 1, 2].
* **Независимость:** архитектура без тяжеловесных сторонних прослоек и лишних зависимостей.
